# Ready-to-use LinkedIn project entry

**Project name:** Meridian — Configurable Portfolio Analytics & Risk Dashboard

**Description:** Built and deployed Meridian, a configurable portfolio analytics web app using Python, FastAPI, React, TypeScript and Plotly.

The application connects Decimal FIFO transaction accounting to cash-flow-aware returns, risk metrics, asset correlations and scenario analysis. Users can choose, resize, reorder and restyle ten analytical sections, inspect portfolio performance and explore seeded Monte Carlo and block-bootstrap simulations.

The numerical engine is covered by 16 Python/API tests and 10 frontend tests, with additional Python/WebAssembly integration checks. The public demo runs custom Python calculations in the browser and uses clearly labelled synthetic EUR data. Simulated outcomes are conditional scenarios, not investment forecasts.
