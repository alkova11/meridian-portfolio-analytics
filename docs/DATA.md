# Data and provenance

All bundled market observations are synthetic, generated by `portfolio_analytics.sample.sample` with NumPy seed 73 and weekday dates from 2024-10-25 to 2026-10-23. EQUA, TECH, EURO, BOND and GOLD are illustrative EUR instruments, not provider tickers. GOLD represents a gold-miner equity ETF, not physical commodity accounting. Benchmark is synthetic EUR equity total return, not S&P 500.

On backend start prices are written to data/processed/synthetic_prices.parquet. No external market provider is used or required. Generated datasets and imported personal transactions are ignored by Git. Run records include frozen transactions, dataset/config/lock hashes, seed, Git state, timestamps and artifact URI. Original CSV imports are preserved locally by content hash. Run exports contain private transaction details; users control the download.

No licensed market data or original reference media are distributed. Real-data providers, FX, exchange holiday calendars and provider corporate-action adapters remain outside v1.
