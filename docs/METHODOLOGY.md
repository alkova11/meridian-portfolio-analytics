# Calculation methods

The ledger applies events in stable date order with arbitrary-precision Decimal values. Buy fees enter lot cost. Sales consume FIFO lots proportionally and subtract sale fees from proceeds. Splits multiply remaining lot units and leave total basis fixed. Dividends add cash; standalone fees reduce cash. Purchases, sales, and splits are internal; deposits and withdrawals are external. No negative cash or short positions.

Daily value V is cash plus quantity times raw closing price. With start-of-day external flow F, r[t] = V[t] / (V[t-1]+F[t]) - 1. Initial wealth is initial external capital. Zero-capital days yield zero return only if ending value is also zero. Time-weighted wealth compounds these returns; cash deposits cannot create returns. Full liquidation and reinvestment are retained in this convention.

Annual volatility = std(r, ddof=1) * sqrt(252). Daily risk-free rate = (1.02)^(1/252)-1. Sharpe = mean(r-rf_daily)*252 / annual volatility. Sortino denominator = sqrt(mean(min(r-rf_daily,0)^2))*sqrt(252). Undefined ratios return null. Drawdown is compounded wealth divided by its running maximum minus one. Recovery is the first post-trough date whose wealth equals/exceeds the pre-trough peak. VaR95 = max(0,-quantile(r,.05)), linear interpolation, one-day horizon. Beta uses sample covariance with aligned benchmark daily returns divided by benchmark sample variance. HHI includes cash.

Simulation estimates mean vector and sample covariance from daily log raw-price returns. Assets evolve by exponentiating joint normal shocks; portfolio values hold initial units and cash constant. A second model samples joint contiguous 5-day historical log-return blocks, preserving cross-asset dependence. No future dividends, interest, trades, or flows are projected; raw-price-only calibration is explicitly a limitation relative to dividend-inclusive historical portfolio TWR. All current sample assets have sufficient history. The model does not promise realistic crash tails or calibrated probabilities. p5/p25/p50/p75/p95 are cross-sectional day-specific quantiles, not individual paths. Terminal mean, median, probability below initial wealth, and p5/p95 boundaries use the same paths.

Scenarios apply either a uniform shock to all current risky holdings or individual observed endpoint price changes from a historical interval. Cash is unchanged and dividends excluded from these price shocks. This is fixed-holdings replay, not historical strategy backtesting.

The below-holdings risk breakdown also reports the annualised downside RMS used in the Sortino denominator. Correlation cells are Pearson correlations of aligned daily log raw-price returns for currently held assets. Cash is excluded because its constant price return has no defined Pearson correlation; any other constant-price series also produces null rather than zero. The heatmap uses a fixed −1/+1 colour scale and the accompanying accessible table reports four decimal places.
