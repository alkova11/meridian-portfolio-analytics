# Contributing

Run the offline checks in the README before proposing changes. Keep accounting/model code in the Python package and UI layout preferences in the frontend. Add independent fixtures for changes to cash flow, cost basis, returns or risk conventions.

Use synthetic or legally redistributable fixtures. Keep private imported transactions, run exports, credentials and original reference media out of commits. Browser tests require both local servers and a matching Playwright browser; explicitly state when they have not run.

A project licence has not yet been selected. Repository preparation does not imply permission to redistribute third-party reference media or contributor code.
